# Sushikeizo

**Systems engineer, game developer, and tooling architect.** I build Luau tooling and asset pipelines for creators, ship native desktop applications in C# and Go, and maintain the Sushikeizo Community's game hub and software stack.

[sushikeizo-games-hub.vercel.app](https://sushikeizo-games-hub.vercel.app) · [Discord](https://discord.gg/gSvWXQX5h8) · [YouTube](https://www.youtube.com/@sushikeizohaha)

---

## What I work on

- **Luau tooling.** Creator scripts, utility libraries, and a public project hub for the Sushikeizo Community.
- **Asset migration.** Bulk pipelines that move animations, sounds, meshes, and gamepasses between places with a desktop UI plus a Studio plugin.
- **Native Windows apps.** Hardware companions, titlebar customizers, and offline utilities written in C# and PowerShell.
- **Backend and offline apps.** Python services for inventory, POS, and school projects with SQLite and CustomTkinter.

## Stack

Luau · Go · C# · C++ · Python · JavaScript · PowerShell
Studio · Open Cloud APIs · Rojo · Aftman · CustomTkinter · Web Serial · REST
